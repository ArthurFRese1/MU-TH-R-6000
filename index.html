Inicie o aplicativo pelo Vite

Esta página foi aberta como arquivo estático. O Live Server (porta 5500) não compila React/TypeScript e por isso a aplicação não pode iniciar aqui.

No VS Code, execute Terminal → Executar Tarefa… → MU/TH/R: iniciar servidor local (Vite). Depois abra o endereço que o Vite mostrar no terminal. Ele costuma começar com http://127.0.0.1:5173/.

Se esta mensagem aparecer mesmo no endereço do Vite, verifique os erros do terminal e recarregue a página.
